# ВидеоКомпас AI

Учебный веб‑сервис для практического задания к занятию №3 курса «Разработка с AI на практике для всех».

Пользователь вставляет ссылку на YouTube. Серверная Vercel Function получает транскрипт через Apify, передаёт его Gemini и возвращает понятный разбор на русском языке.

## Что умеет сервис

- принимает обычные ссылки YouTube, `youtu.be`, Shorts, Live и Embed;
- получает только один публичный транскрипт за запрос;
- создаёт резюме, выделяет ключевые идеи и целевую аудиторию;
- оценивает пользу ролика от 0 до 100;
- предлагает практические действия и вопросы для самопроверки;
- не передаёт API‑ключи в браузер;
- понятно сообщает об ошибках и отсутствии субтитров.

## Как устроен проект

```text
index.html, styles.css, script.js  — интерфейс
api/analyze.js                     — серверная Vercel Function
lib/                               — проверка ссылок, подготовка текста и промпт
test/                              — автоматические тесты
scripts/dev-server.js              — локальный сервер без дополнительных пакетов
```

Внешние сервисы:

1. Apify Actor `scrape-creators/best-youtube-transcripts-scraper` получает субтитры.
2. Gemini `gemini-3.7-flash` анализирует текст.
3. Vercel публикует статический интерфейс и запускает серверную функцию.

## Безопасная настройка ключей

Нужны две серверные переменные:

```text
APIFY_API_TOKEN
GEMINI_API_KEY
```

Важно:

- не отправляйте значения ключей в чат;
- не вставляйте ключи в `script.js` или другие публичные файлы;
- не добавляйте `.env.local` в Git;
- в Apify создайте отдельный ограниченный токен для этого проекта;
- в Vercel добавьте обе переменные для Production и Preview, затем выполните Redeploy.

Файл `.env.example` содержит только названия переменных без секретов.

## Локальная проверка

Требуется Node.js 22 или новее.

```powershell
npm test
npm run dev
```

После запуска откройте `http://127.0.0.1:3000`.

Без API‑ключей можно проверить страницу, валидацию ссылок и понятное сообщение о ненастроенном сервисе. Полный внешний поток проверяется после добавления переменных в Vercel.

## Публикация GitHub → Vercel

1. Создайте публичный репозиторий `video-compass-ai-4216`.
2. Отправьте ветку `main` в этот репозиторий.
3. В Vercel нажмите **New Project** и импортируйте GitHub‑репозиторий.
4. Framework Preset оставьте **Other**.
5. В Environment Variables добавьте `APIFY_API_TOKEN` и `GEMINI_API_KEY`.
6. Нажмите **Deploy**.
7. Проверьте production‑ссылку в режиме инкогнито.

После подключения GitHub каждый новый push в `main` автоматически создаёт новый production‑деплой.

## Проверка перед сдачей

```powershell
npm test
```

Дополнительно проверьте:

- обычную ссылку YouTube с субтитрами;
- короткую ссылку `youtu.be`;
- Shorts;
- ссылку не на YouTube;
- ролик без доступных субтитров;
- мобильную ширину окна;
- отсутствие ключей командой `git grep -n "APIFY_API_TOKEN\|GEMINI_API_KEY"` — допустимы только названия переменных, но не их значения.

## Ограничения

- поддерживается один ролик за запрос;
- закрытые и возрастные видео могут не возвращать субтитры;
- длинные транскрипты сокращаются до 60 000 символов с сохранением начала, середины и конца;
- AI‑ответ может содержать неточности, поэтому важные выводы нужно сверять с оригиналом.
